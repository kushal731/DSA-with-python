This repository contains Python programs for Data Structures and Algorithms (DSA) with Python, covering Weeks 1-13 of the course syllabus from Siddaganga Polytechnic, Tumkur (20CS41P / 20IS41P).

## Requirements

- Python 3.x
- matplotlib (for asymptotic notation graphs)

Install matplotlib:
```bash
pip install matplotlib
```

## How to Run

Navigate to the `programs/` directory and run any program:

```bash
cd programs
python program_name.py
```

Example:
```bash
python stack_data_structure.py
```
